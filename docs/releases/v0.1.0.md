# AnyGame v0.1.0 — first release

AnyGame is a desktop library and conversion front end for
[AnyPS5](https://github.com/boykopovar/AnyPS5). It turns an extracted,
decrypted PS5 title into a runnable Linux or Windows package and keeps the
conversion toolchain, library, patches and diagnostics in one place.

This is the first public release.

## Features

- **Desktop library** with real title icons, status, per-game drawer and
  search.
- **AnyPS5 updater** for Linux and Windows runtimes, with SHA-256 verification
  and atomic installs.
- **One-click conversion**:
  - unwraps SELF executables and bundled modules, including
    `Media/Modules`/`Media/Plugins`;
  - passes guest modules to the official relinker;
  - assembles `libs/`, `app0/`, launchers and metadata;
  - resolves host dependencies, module dependencies and phantom `DT_NEEDED`
    entries.
- **Package verification** (`anygame verify`) without launching the game.
- **Post-build diagnostics** (`anygame diagnose`): runs the title for a bounded
  time, reports missing libraries/files, fatal errors and window state.
- **Per-game performance settings**: FPS limit, reported resolution, FSR,
  present mode, texture-cache budget, GPU and fullscreen.
- **Patch catalog** in AnyPS5's documented format, with title/version matching,
  SHA-256 checks and one-patch selection.
- **Community page** with GitHub Device Flow and fine-grained PAT login for the
  upcoming in-app patch submission.
- **CLI** for scripts and servers: `update`, `info`, `build`, `verify`,
  `diagnose`, `patches`, `run`, `unwrap`, `doctor`.

## Downloads

| Asset | Platform |
|---|---|
| `AnyGame-0.1.0-x86_64.AppImage` | Linux x86-64 |
| `AnyGame-0.1.0-windows-x64.zip` | Windows x86-64 |
| `SHA256SUMS` | Hashes for both |

Linux:

```sh
chmod +x AnyGame-0.1.0-x86_64.AppImage
./AnyGame-0.1.0-x86_64.AppImage
```

Windows: extract the ZIP and run `AnyGame.exe`.

The AppImage starts Electron with `--no-sandbox` because Chromium's sandbox is
not available inside an unprivileged mounted image. The UI loads only local
files and has no network access from the renderer.

## Requirements

- x86-64 host (Linux or Windows). ARM is not supported yet.
- Go 1.22+ only if you build from source.
- A Vulkan 1.1 GPU and current driver to run converted titles.
- A **legal, personal copy** of the game, extracted and decrypted. AnyGame does
  not decrypt games or bypass protections.

## Data

- Runtimes, library and settings:
  Linux `~/.local/share/AnyGame`, Windows `%LOCALAPPDATA%\AnyGame`
  (override with `ANYGAME_HOME`).
- Each converted package is self-contained (`libs/`, `app0/`, executable).
- No telemetry; see [PRIVACY.md](https://github.com/TuxArchi/AnyGame/blob/main/PRIVACY.md).

## Known limitations

- No decryption, PKG extraction, firmware, keys or PSN services.
- Incomplete dumps convert but may fail at runtime; `diagnose` reports missing
  files.
- Windows deep import verification and automatic PR submission are still on the
  roadmap.
- The bundled patch catalog is empty; configure a community catalog or publish
  your own.
- Compatibility depends on AnyPS5's per-title status; this release does not
  promise a specific game runs.
