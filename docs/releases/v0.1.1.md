# AnyGame v0.1.1 — Windows parity

AnyGame is a desktop library and conversion front end for
[AnyPS5](https://github.com/boykopovar/AnyPS5). This release completes the
Windows-side dependency checks and diagnostics.

> **Support AnyGame:** if it saves you time, you can invite me to a coffee at
> **https://ko-fi.com/tuxarchi**. Support is optional; reproducible reports and
> patch contributions help just as much.

## What changed on Windows

- **PE import verification**: `anygame verify` reads the executable's PE import
  table (including imports without an `.idata` section) and resolves every DLL.
- **Converted module dependencies**: the package closure now includes the
  `<stem>.<module>.needed.json` files the relinker writes for each module, so a
  plugin's host libraries cannot be left out.
- **Windows diagnostics**: the diagnostic run creates a new process group,
  hides the console and kills the whole process tree with `taskkill`.
- **Vulkan detection**: `anygame doctor` looks for `vulkan-1.dll` in
  `System32` and `PATH`; the CPU extension check is delegated to AnyPS5 at
  launch.
- **CI**: the Windows test suite is green, including the updater fixture and
  permission checks.

Linux users get the same module-dependency closure; no UI or gameplay behavior
changed.
